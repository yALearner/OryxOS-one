## Loop 编程专用提示词（AI Agent 上下文注入）

> 以下提示词可直接注入给 AI 编程 Loop（如 Claude Code / Cursor / Copilot），使其快速理解 OryxOS 项目全貌并继续开发。

```markdown
# OryxOS 项目上下文

## 项目定位
OryxOS 是用 Java 21 + Spring Boot 3.5 实现的面向企业场景的 Agent OS（Agent 统一底座）。
装在企业自己的 K8s 或服务器上，作为统一底座运行多个业务 Agent，共享渠道接入、模型路由、
工具调用、记忆系统、沙箱执行能力。数据完全留在企业自己的基础设施，不锁任何云生态。
Agent 在 OryxOS 上是**配置出来的，不是写代码写出来的**。

## 当前阶段
**核心阶段（pre-alpha）第一周**：ReAct Runtime 功能 spec-kit 规划全部完成
（specify → clarify → plan → tasks → analyze 闭环），即将进入实施。
实施入口：`specs/001-react-runtime/tasks.md`（69 个任务，从 T001 开始）。

## 9 个 Maven 模块（骨架已初始化，业务代码待实施）

| 模块 | 职责 |
|------|------|
| `oryxos-core` | 核心抽象：ReActLoop、PromptBuilder、ToolExecutor、AgentService、AgentScheduler |
| `oryxos-provider` | LLM Provider 抽象，多 Provider 显式映射（Map<name, ChatModel>） |
| `oryxos-memory` | MemoryService 统一门面，LongTermMemory 可插拔后端 |
| `oryxos-tool` | 内置 Tool、MCP Client、ToolRegistry、Sandbox、NotifyTools 合并模块 |
| `oryxos-channel-cli` | CLI Channel 交互式对话 |
| `oryxos-web` | REST API（10 个端点）、GlobalExceptionHandler、OpenAPI |
| `oryxos-storage` | SQLite 持久化、审计表（tool_invocations + llm_calls）写入 |
| `oryxos-cli` | Picocli 命令行入口（12 个子命令）、ConfigLoader |
| `oryxos-boot` | Spring Boot 启动模块、自动配置、依赖聚合 |

**依赖方向**：storage 被 core 与能力层依赖；provider/memory/tool 依赖 core；
web/channel-cli 依赖所有能力层；cli 组装所有模块；boot 做依赖聚合。

## 关键设计决策（不可违背，宪法 9 条）

1. **ReAct Loop 自实现**：不用 Spring AI 的 Agent 抽象，自己写核心循环
2. **Spring AI 只用两件事**：LLM Provider 协议转换 + @Tool JSON Schema 生成。
   禁用自动 tool 执行（`ToolCallingChatOptions.internalToolExecutionEnabled(false)`，
   调度完全由 ReActLoop + ToolExecutor 控制；代码禁用 ChatClient）
3. **Provider 显式映射**：Map<String, ChatModel>，不靠类型扫描
4. **一个目录 = 一个 Agent**：.oryxos/agents/<name>/AGENT.md（frontmatter + 正文）；
   Skill 以软连接绑定、渐进式披露，frontmatter 不声明 skills:
5. **审计 Day One**：tool_invocations + llm_calls 两张表从核心阶段就写入 SQLite
6. **同步执行模型**：全程同步阻塞 + Java 21 Virtual Thread，不引入 Reactor/WebFlux
7. **不用 SecurityManager**：Sandbox 接口先行（enforce(SandboxAction)），
   核心阶段 WhitelistSandbox 三层白名单
8. **三种触发源共用一个引擎**：CLI/Web/Scheduler → AgentService.process() → ReActLoop
9. **Tool 模块三合一**：内置 Tool + MCP Client + Sandbox + NotifyTools 合并在 oryxos-tool

## 技术栈（GA 版本线，2026-08 已定）
- Java 21（Temurin 21.0.12.1）+ Spring Boot **3.5.16** + Maven **3.9.16**（多模块）
- Spring AI **1.1.8 GA**：官方 `spring-ai-starter-model-openai` 对接 DeepSeek/Kimi
  （base-url 不带 /v1：DeepSeek `https://api.deepseek.com`、Kimi `https://api.moonshot.cn`）。
  **spring-ai-alibaba 已移除**（无 OpenAI 兼容 starter，仅 DashScope；未来需要 Qwen 再按 GA 线引入）
- Picocli 4.7.6（CLI）、SnakeYAML 2.2（配置）、SQLite + Spring Data JPA（审计）
- `hibernate-community-dialects`（SQLiteDialect）+ `spring.sql.init.mode=always` 手动 schema.sql
- Logback 1.5.x + `logstash-logback-encoder:8.0`（结构化 JSON 日志）
- 核心阶段无需 PostgreSQL、Redis 等外部依赖
```
